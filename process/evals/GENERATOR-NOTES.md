# Generator notes -- M4 PDF Report Generation

## What was built

### 1. `src/components/report/pdfReport.ts` -- Full PDF report generation

Replaced the stub file with a complete implementation using jsPDF directly (no html2canvas). Two exported functions:

**`generateSingleScenarioPdf(name, state, result)`** -- Single-scenario A4 portrait PDF:

- **Page 1 (Cover):** Teal header band, scenario name as title, allocation method via `granularityLabel()`, hourly score, annual score, excess MWh, unmatched demand MWh, and portfolio summary (total demand, total generation, consumer/generator counts).
- **Page 2 (Inputs):** Every consumer listed with name and annual MWh. Every generator listed with name, annual MWh, and technology. Allocation matrix table with header row, alternating row backgrounds, and percentage values.
- **Page 2 or 3 (Chart):** Monthly bar chart drawn on a canvas element and added as a PNG image. Shows matched MWh (teal), unmatched demand (grey), and excess (lighter teal) bars for each month. Includes Y-axis labels with MWh values, X-axis month abbreviations, dotted grid lines, and a legend.
- **Footer on every page:** "Generated by Granular Energy Scenario Analysis Tool, granular-energy.com"

**`generateComparisonPdf(scenarios)`** -- Comparison A4 landscape PDF:

- **Page 1 (Tiles):** Teal header band with title. One card per scenario showing name (with coloured dot matching series colours), hourly score, annual score, excess MWh, unmatched MWh.
- **Page 1 (Chart):** Monthly score line chart drawn on canvas. One line per scenario using the series colours (#00988b, #e9a23b, #0f4974, #ab80cc). Data markers, dotted grid lines, and legend.
- **Page 1 or 2 (Assumptions):** Table with rows for allocation method, consumers, and generators. Header row with scenario names. Differing cells highlighted with warning background colour.
- **Footer on every page:** "Generated by Granular Energy Scenario Analysis Tool, granular-energy.com"

### 2. `src/components/compare/CompareTab.tsx` -- Wired up comparison PDF

- Imported `generateComparisonPdf` and `ComparisonScenario` from the report module.
- Replaced the stub `handleDownloadPdf` callback (which only logged to console) with real implementation that maps selected scenarios to `ComparisonScenario[]` and calls `generateComparisonPdf`.
- Moved `selectedScenarios` declaration before `handleDownloadPdf` to avoid block-scoped variable reference error.

### 3. `tests/e2e/m4-pdf-report.spec.ts` -- Playwright e2e tests (2 tests)

- **Single scenario PDF download:** Navigates to Results tab, clicks "Download report", asserts download event fires with filename matching `-report.pdf`.
- **Comparison PDF download:** Injects two scenarios with differing granularities, navigates to Compare tab, selects both, clicks "Download comparison PDF", asserts download event fires with filename `scenario-comparison.pdf`.

### Design token usage

All colours in the PDF module are defined as constants sourced from the design tokens:
- Teal accent: `#00988b`
- Neutral scale: `#2a2929`, `#56514e`, `#897f78`, `#e3e0dd`, `#f2efed`, `#fbfaf9`
- Series colours: `#00988b`, `#e9a23b`, `#0f4974`, `#ab80cc`
- Teal header band: `#e6f5f3`
- Excess bar fill: `#94d1cc` (teal-500)

No hard-coded colours outside these constants.

### Implementation notes

- Uses jsPDF text/drawing primitives for all text, tables, and shapes.
- Charts are drawn on HTML canvas elements and added as PNG images via `doc.addImage()`.
- The monthly bar chart stacking order follows the design spec: matched at bottom, unmatched above, excess on top.
- Hex-to-RGB conversion helper avoids `any` types by returning typed tuples.
- The `MatchingGranularity` import was initially included but removed as unused (only `granularityLabel` is needed, not the type directly).
- British English in all function/variable names (colour, sanitise) and UI copy.
- TypeScript strict with no `any` types.
