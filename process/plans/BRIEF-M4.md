# Milestone M4 brief: Scenarios, Compare, reports and lead capture

In scope:
- Save scenario (name, timestamp) from the Results tab: stores portfolio, matrix, granularity, results summary and any uploaded profiles in localStorage. List, rename, delete, and load a saved scenario back into the builder.
- Scenario file: download as `.json` (self-contained, including uploaded profile data) and import from file, with validation and a clear error for bad files. Not gated.
- Compare tab: choose up to 4 saved scenarios; show per scenario a tile column (hourly, annual, excess, unmatched), an overlaid monthly score chart (one series per scenario, `--ge-series-1..4`), an assumptions table (consumers with sizing, generators with sizing, matrix, granularity) with cells that differ between scenarios highlighted, and a per-consumer score table.
- PDF report for one scenario: cover (scores, granularity), inputs (every profile, sizing, matrix, upload timezone/unit), the Results charts, footer "Generated by Granular Energy Scenario Analysis Tool, granular-energy.com". A4 portrait, multi-page allowed. Built with html2canvas + jsPDF from a print-layout React tree.
- Comparison PDF: the Compare tab as a one- or two-page A4 landscape.
- HubSpot gate: before any PDF download, show a modal with the HubSpot form (portal/form IDs from `src/config.ts`, placeholders until marketing supplies them, with a visible "development mode: form not configured" notice when placeholders are in use). On form submit, unlock downloads and remember in localStorage.

Out of scope: hourly CSV export, backend storage, accounts.
