# Milestone M3b: Review changes to Portfolio, Allocation and Results

## Scope

Generator sizing moves from installed MW to annual MWh, with an implied-capacity hint and state migration for existing portfolios. The allocation matrix gains volume display (MWh alongside %) with a toggle for input mode, plus row/column totals. The matching granularity selector gets full explanations of each method. The Sankey chart is redesigned with a three-column layout (Generators → Consumers → Outcomes) and must balance flows; stale-node and duplicate-label bugs are fixed. All three bar charts (average day, monthly breakdown, example day) adopt the correct stacking order: matched → excess → unmatched → demand spline. Two open FEEDBACK.md items are closed.

## Out of scope

- Scenarios, Compare, PDF, HubSpot (M4).
- New chart types or new tabs.
- Changes to the engine algorithm or golden fixture values.
- Upload flow changes.

## Notes for the generator

- The `PortfolioGenerator` type currently has `capacityMW` and `capacityFactor`. It needs to change to `annualMWh` (with `capacityFactor` retained for the hint computation). The `UPDATE_GENERATOR_SIZING` action payload must change from `capacityMW` to `annualMWh`. Add a migration function in the state-loading path that detects the old schema and converts.
- The engine input is unchanged: hourly generation MWh is computed as `shape × annualMWh` (previously `shape × capacityMW × capacityFactor × 8760`). The golden fixtures must not change; verify with `npm test` early and often.
- The Sankey builder currently uses two columns. Redesign it to three. Use a fresh React `key` on the chart component when the consumer selector changes, so Highcharts fully recreates the chart (avoids stale nodes). Set `dataLabels.enabled: true` only on nodes, not links, to avoid double labels.
- For bar chart stacking, check the reference screenshot at `process/research/reference-platform-demand-allocation-chart.webp`. The current average-day and example-day configs lack per-generator excess series; add them following the same pattern as the monthly breakdown, but with the corrected stacking order (matched → excess → unmatched).
- The granularity description copy in M3b.10 is long; consider an expandable/collapsible panel or a contained card per option so it does not overwhelm the Allocation tab, especially on mobile.
- Mark the three FEEDBACK.md items as `[fixed in M3b]` when done. The "Sankey Unallocated label" item is superseded by the full Sankey redesign in this milestone.
