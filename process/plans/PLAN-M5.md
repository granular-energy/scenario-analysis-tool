## Notes for the generator

- **PDF chart upgrade.** The brief specifically asks for screen-fidelity charts in the PDFs. The current `pdfReport.ts` draws simplified bar charts using canvas 2D primitives. Replace these with Highcharts-rendered images. The recommended approach: render the Highcharts chart off-screen (or use `chart.getSVG()` → convert to canvas → `toDataURL`), then embed the image via `doc.addImage()`. Keep the existing page structure and footer; only the chart rendering method changes. The `canvg` library is already available as a dependency (via highcharts export).
- **No HubSpot gate.** The brief explicitly states no HubSpot gate should be added. Keep existing ungated PDF download paths.
- **Allocation method naming.** The Allocation tab's selector is already labelled "Allocation method". Keep all copy consistent with this. The annual score is volumetric and may exceed 100 % — do not cap or reformat it.
- **Playwright config.** The `webServer` in `playwright.config.ts` builds before serving. Never start a separate preview on port 4173. All e2e tests use the config's built-in server.
- **Demo portfolio golden numbers.** Hourly granularity: hourly score 67.33 %, annual score 100.74 %, excess 0 MWh, unmatched ~16,335 MWh, total demand 50,000 MWh. Consumer "Data centre" scores identical to portfolio (single consumer). Generators: Solar PV temperate 24,090 MWh, Wind onshore temperate 26,280 MWh. Matrix: 100 %/100 %.
- **Lazy-loading profiles.** The 16 profile JSON files are ~1.5 MB total. Use dynamic `import()` or `fetch()` to load them on demand rather than bundling them into the initial chunk. The registry.json (small metadata) can remain in the main bundle.
- **British English.** Be careful with CSS property names like `backgroundColor` — these are code, not UI copy, and should not be changed. The check targets only user-visible strings in JSX and string literals.
- **FEEDBACK.md.** All existing items appear to be marked as fixed. Verify this is still the case after all M5 changes, and add any new items discovered during the polish pass.
- **Existing hard-coded colours.** The Grep scan found a small number of hard-coded hex values in `CompareTab.tsx` and `CompareColumns.tsx`. These must be replaced with token references or Highcharts config that uses the shared token constants.
